# Temperature conversion utilities

Create a file `temperature.js` in the workspace providing conversions between Celsius and Fahrenheit.

## Acceptance Criteria

- [ ] `temperature.js` exports `celsiusToFahrenheit(c)` and `fahrenheitToCelsius(f)` via CommonJS `module.exports`
- [ ] `celsiusToFahrenheit(100)` returns 212
- [ ] `fahrenheitToCelsius(32)` returns 0
- [ ] Both functions return numbers
- [ ] The file is syntactically valid JavaScript
