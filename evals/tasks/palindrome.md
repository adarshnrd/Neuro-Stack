# Palindrome checker

Create a file `palindrome.js` in the workspace with a function that checks whether a string is a palindrome, ignoring case, spaces, and punctuation.

## Acceptance Criteria

- [ ] `palindrome.js` exports a function `isPalindrome(text)` using CommonJS `module.exports`
- [ ] Comparison ignores case, whitespace, and non-alphanumeric characters
- [ ] Returns a boolean
- [ ] `isPalindrome("A man, a plan, a canal: Panama")` returns true
- [ ] The file is syntactically valid JavaScript
