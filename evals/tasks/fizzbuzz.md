# FizzBuzz module

Create a file `fizzbuzz.js` in the workspace that implements the classic FizzBuzz logic as a reusable function.

## Acceptance Criteria

- [ ] `fizzbuzz.js` exports a function `fizzbuzz(n)` using CommonJS `module.exports`
- [ ] Returns "Fizz" for multiples of 3, "Buzz" for multiples of 5, "FizzBuzz" for multiples of 15
- [ ] Returns the number itself as a string for all other values
- [ ] The file is syntactically valid JavaScript
