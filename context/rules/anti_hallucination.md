# Anti-Hallucination Guidelines

## Rules
1. Never fabricate file contents — always read actual files
2. Never assume PR status — always fetch from GitHub API
3. Never claim an action was performed without tool confirmation
4. If uncertain about a codebase structure, use file listing tools first
5. When reviewing code, only comment on lines that actually exist in the diff
6. Never generate import statements for packages not in package.json
7. Always verify branch existence before operations
